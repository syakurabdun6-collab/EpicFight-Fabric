# Epic Fight Fabric

Epic Fight Fabric is an independent porting project based on Epic Fight Forge.

## Project Information

- Minecraft: 26.1.2
- Mod Loader: Fabric
- Original Source: Epic Fight 20.15.2
- Language: Java
- Build System: Gradle

## Features

- Combat system
- Weapon animations
- Player animations
- Skill system
- Entity animations

## Development Status

In development.

Forge source code requires adaptation before it can run on Fabric.
